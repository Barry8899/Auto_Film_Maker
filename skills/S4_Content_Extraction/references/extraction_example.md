## 第一层，通用内容元素
包含五个通用元素维度，不依赖影片类型，任何宣传片都需要提取的元素。具体如下：

**抽取维度A: 空间/环境**
 - 大全景: 如城市天际线/荒野地平线/宫殿全貌
 - 标志性场景: 如霓虹招牌/古桥流水/太空舱门

**抽取维度B: 人物/情绪**
 - 面部特写: 如皱眉/嘴角鬼魅一笑/泪光闪烁
 - 手部/眼神细节: 如手上青筋暴起/攥紧拳头/惊恐的瞳孔

**抽取维度C: 动作/行为**
 - 爆发瞬间: 如突发爆炸/打斗/奔跑
 - 蓄力预备: 如缓慢拔剑/变身/施法/扣动扳机
 - 定格收束: 如主角落地/战损站立/死亡

**抽取维度D: 对话/声音**
 - 旁白/独白: 如"我等了三十年"/"我究竟是谁"
 - 情绪呼号: 如"啊！！——"/"RUN！！——"

**抽取维度E: 光影/氛围**
 - 高对比剪影: 如人物轮廓/建筑线条/武器形态
 - 冷暖色调: 如橙红篝火对湛蓝湖水/冰雪冷白对室内暖黄

## 第二层 **特定类型元素**
基于影片类型或用户预期风格，叠加专属标签。示例如下:

```json
{
 "科幻片": {
 "科技界面": "如HUD抬头显示/全息投影/数据瀑布",
 "机械细节": "如机甲变形/武器展开/舱门开启",
 "异星景观": "如双日天空/非地球地貌/巨型建筑"
 },
 "悬疑片": {
 "窥视视角": "如门缝偷窥/监控画面/后视镜反射",
 "隐喻物品": "如老旧钟表/未接来电/半燃香烟",
 "空间压迫": "如狭长走廊/密闭电梯/单向镜"
 },
 "动作片": {
 "武器特写": "如冷兵器出鞘/枪械上膛/弹药填装",
 "破坏瞬间": "如玻璃炸裂/墙体崩塌/火花四溅",
 "慢动作点": "如水滴飞溅/羽毛飘落/弹壳落地"
 }
}
```

## 第三层：**特定IP元素**
若 Agent 或用户对原片已有充足的认知积累，如经典台词，主角高光等，可直接注入标志性符号。此处以《复联4》为例

```json
{
 "复联4特定IP元素": {
 "经典台词": ["whatever it takes", "advengers assemble"],
 "主角高光": ["美队举锤", "黑寡妇献祭", "复联集结"],
 "特定符号": "如六颗宝石/五星盾牌"
 }
}
```
